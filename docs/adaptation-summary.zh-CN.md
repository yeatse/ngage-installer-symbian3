# N-Gage 2.0 Symbian^3 适配总结

交付版本为 1.30(1550)，以 N97 的 N-Gage 1.30(1541) 为基础。
用户已在 Nokia 808 Belle FP2（Install Server、Open4All）验证游戏、声音、
系统音量键和 L/R；模拟器使用本地 Linux EKA2L1 和 N97/X7 ROM 验证流程。
验证游戏为 Hooked: Creatures of the Deep，不代表所有 N-Gage 游戏和机型均兼容。

## 安装与运行

修正旧 SIS 组件的平台依赖和空平台声明，增加 Symbian^3/Belle 识别，
在新系统选择原有 N97 触控配置。修正组件 UID、版本、E32 头校验和 SIS 哈希，
使破解设备能够覆盖升级，不需要重新签名。

保留 Games 安装和启动游戏的流程：把 `.n-gage` 放进 `E:\n-gage`，
在 Games 内安装并从封面启动。触控服务在后台运行，不注册额外 Games(Touch) 图标。
普通包沿用真机安装服务；提供的 X7 定制 ROM 单独使用带安装服务兼容修复的包，
避免在 808 上覆盖已有服务。

## 显示与触控

实现原生 Display Posting API 兼容 DLL，通过手机已有的窗口和位图服务显示游戏，
支持缓冲区提交、裁剪、缩放及 RGB565/RGB888/RGBx888 转换。
修正 DLL capability 为 ALL-TCB，匹配窗口/位图依赖，解决真机加载返回 -46 后崩溃。
没有为真机添加 ROM 不具备的接口。

加入半透明方形虚拟键：左侧五向键，右侧自上而下 R/A/B/L，左上角展开/收起。
处理按住、重复、多指及收起/焦点变化时释放按键，避免卡键。

L/R 不能仅用 Enter/Backspace 模拟。根据 NGI 原有触摸路径，给固定版本
`ngiinput.dll` 的 32 位和内部 64 位查询增加源码编译的 Thumb 适配，
把 Device0/Device1 转成真实逻辑软键位 0x1000/0x2000，其他键保留原查询。
构建时校验上游 SHA、指令位置、重定位和包内两份副本，并在 ARM CPU 中执行验证 ABI。

## 声音与系统音量

将 NGI 音频库的 MMF 导入转到源码编译的桥接 DLL，再转发到 ROM DevSound，
保留原 NGI 音频指令及调用参数、栈、返回约定。

真机日志确认 NGI 请求 7、设备最大值为 10000；按原值设置导致声音几乎不可闻。
将旧 0–10 音量换算到实际设备范围，例如 7 → 7000；最大值为 10 时仍为 7，静音仍为 0。

在游戏音频线程内接入 RemCon Core API，支持实体音量键单按、按住和释放，
带有界重复，直接调整当前 DevSound 实例。处理暂停恢复、游戏自身音量变化、
停止后清除实例引用，以及回调期间 DLL 保持加载，避免悬空对象或代码地址。

## 工程与验证

使用 symbian-platform 0.3.0 在 Linux 从源码编译原生组件并生成 unsigned SIS。
GitHub Actions 自动构建和上传产物；大型上游安装器、SDK 和 X7 服务按 SHA-256 缓存，
恢复后再校验，不在常规构建中下载 ROM 和游戏。

24 项工程检查覆盖包结构、原始输入保护、导入替换、组件身份、音量换算、
软键 Thumb 执行及 ABI。流程验证覆盖 N97 基线、X7 中 Games 安装/启动与菜单/游戏画面，
以及 808 的用户实测。

遇到的 EKA2L1 契约问题在独立分支修复，包括安装 IPC、动态库 capability 检查和
RemCon v2 的会话角色识别；没有把模拟器专用接口放进真机组件。
最后一次模拟器回归为 466 项测试、33469 条断言通过。
具体提交与过程证据见 validation/README.md 和 EKA2L1 分支历史。

1550 清除用于定位问题的崩溃子探针、进程退出监视、文件日志、诊断计数器和诊断构建入口。
保留 1549 已验证的兼容功能。旧日志不自动删除，升级后须重启以替换常驻服务及 DLL。
